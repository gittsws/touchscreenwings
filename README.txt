❔『觸熒展翅』
為觸摸式熒幕加上翅膀，自由翱翔
本應用程式透過藍牙協定使目標裝置的觸摸式熒幕操作變得十分便捷
本機作業系統最低需要安卓9(=level 28)
遠機作業系統一般僅需支援藍牙和觸熒

────運作原理────
本軟體的運作為，控制端=本機，被控端=遠機，兩端透過藍牙協定連接，由本機向遠機發送藍牙信號來操作遠機的觸熒。
本應用程式安裝在本機上，遠機上不需要。
本機必須是安卓系統，可以是安卓手機、安卓平板，最好帶有【陀螺儀】功能。
遠機不一定是安卓系統，可以是安卓手機、安卓平板、蘋果手機、蘋果平板…

────注意事項────
　　🔗本機和遠機必須先建立藍牙配對。配對方法：本機和遠機都打開藍牙開關，然後，在其中一方的藍牙裝置表上找到另一方，點擊配對。
　　🚫為了避免本機控件反應遲鈍，本機上必須關閉安卓智機的三連擊“放大手勢”。一般的關閉方法：本機系統設定→輔助功能→無障礙→放大手勢∶關閉。
　　⚪為了便於看見遠機觸熒動作、測試點位置，遠機上建議打開“顯示觸摸操作”。一般的打開方法：遠機系統設定→關於→五連擊版本號，然後，系統設定→系統和更新→開發人員選項→“輸入”段→顯示觸摸操作∶打開。
